## 2. 变更点（本单要落的口径）

1. 导出请求改为 `POST /zip`，请求体 `{ "task_id": "st_<24位小写十六进制>", "indexes": [7,1,7] }`；`indexes` 可省略，省略即该 task 全部已转存图片；不再发送 `cloudIDs`、`zipName`。
2. 成功响应按 `ok`、`fileID`、`bytes`、`count` 四字段读取；`fileID` 以 `cloud://` 开头，可直接作为 `wx.cloud.downloadFile({ fileID })` 的入参；不再读 `cloudID`。
3. 端侧动作：`wx.cloud.downloadFile` 拿 tempFilePath → `wx.shareFileMessage({ filePath, fileName })` 唤起微信会话选择；PC 端降级 `wx.saveFileToDisk`。提示文案「ZIP 已生成，请选择微信好友与文件传输助手进行保存」保持不变。
4. 失败响应一律 `ok=false` 且不含 `fileID`，错误码按 l6 固定表：400 `INVALID_REQUEST`、410 `STAGE_EXPIRED`、413 `TOO_LARGE`、503 `ZIP_NOT_READY`（retryable）、502 `ZIP_FAILED`（retryable）、504 `TIMEOUT`。前端映射人话文案：任务已过期请重新解析；图片数量或体积超限；服务尚未准备好请稍后重试；打包失败请重试；超时请重试。
